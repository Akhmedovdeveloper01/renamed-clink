# Плейсхолдер-изображения

Все файлы в этой папке — сгенерированные SVG-заглушки (градиенты в фирменных цветах), не фотографии реальных людей. Замените их на реальные материалы клиники перед публикацией сайта.

## specialists/

`placeholder-1.svg` … `placeholder-4.svg` — фото сотрудников из `data/specialists.ts`.
Замените на реальные фото специалистов (только с их согласия), формат `.jpg`/`.webp`, соотношение сторон 4:5.

## before-after/

`before-1.svg`, `after-1.svg` — используются в компоненте `components/sections/before-after.tsx`.

**Важно:** реальные фотографии «до/после» клиентов можно публиковать только с письменного согласия клиента. До получения такого согласия используйте только нейтральные плейсхолдеры.
