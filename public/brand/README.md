# Логотип

Сейчас логотип отрисовывается программно как SVG-плейсхолдер в `components/ui/logo.tsx` (монограмма «RM» на синем градиенте + текст «RENAMED» / «— AESTHETIC —»).

Когда будет готов настоящий файл логотипа:

1. Положите его сюда (например `logo.svg` или `logo.png`, а также favicon-версию при необходимости).
2. В `components/ui/logo.tsx` замените содержимое `LogoMark` (и при необходимости `Logo`) на `<Image src="/brand/logo.svg" ... />`.
3. Если понадобится обновить иконку вкладки браузера — отредактируйте `app/icon.tsx` и `app/apple-icon.tsx` (сейчас они генерируют иконку с монограммой «RM» программно).
