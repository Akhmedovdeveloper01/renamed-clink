# RENAMED Aesthetic Clinic — сайт клиники

Премиальный маркетинговый сайт эстетической клиники RENAMED (Самарканд). Next.js (App Router) + TypeScript + Tailwind CSS, с поддержкой двух языков (узбекский / русский) и тёмной/светлой темы.

## Стек технологий

- **Next.js 16** (App Router) + **TypeScript** (strict)
- **Tailwind CSS 4**
- **motion** (Framer Motion) — анимации, **lenis** — плавный скролл
- **next-intl** — интернационализация (uz / ru)
- **next-themes** — тёмная/светлая тема
- **react-hook-form** + **zod** — форма записи с валидацией
- **lucide-react** — иконки

## 1. Как запустить проект

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) — вас автоматически перенаправит на `/uz` или `/ru` в зависимости от языка браузера.

Сборка для продакшена:

```bash
npm run build
npm run start
```

Проверка кода линтером:

```bash
npm run lint
```

```

app/icon.tsx, apple-icon.tsx, [locale]/opengraph-image.tsx — генерируемые иконки/OG-картинка

components/sections/               — секции лендинга (Hero, Promotions, Services, Articles, ...)

components/ui/                     — переиспользуемые UI-компоненты (карточки, аккордеон, слайдер и т.д.)
components/motion/                 — анимационные примитивы (reveal, magnetic button, счётчик и т.д.)

```

## 3. Как редактировать тексты

Все тексты интерфейса (меню, кнопки, заголовки секций, подписи формы и т.д.) находятся в:

- `messages/uz.json` — узбекский (латиница)
- `messages/ru.json` — русский

Структура ключей одинаковая в обоих файлах — просто найдите нужный раздел (`hero`, `about`, `services`, `booking`, `contacts` и т.д.) и отредактируйте значение. Компоненты не содержат текстов «внутри себя», поэтому изменения в JSON сразу отражаются на сайте.

## 4. Как редактировать данные (услуги, акции, статьи, специалисты, отзывы, FAQ)

Контентные данные (не UI-тексты, а именно карточки/списки) лежат в папке `data/`:

- `data/services.ts` — 6 услуг с полной схемой (что это, показания, преимущества, этапы, подготовка/уход, противопоказания, факты, FAQ, похожие услуги, SEO)
- `data/categories.ts` — 4 категории услуг (лицо, лазер, инъекции, коррекция фигуры), используются для фильтров
- `data/promotions.ts` — акции: старая/новая цена, даты начала/окончания, привязка к услуге
- `data/articles.ts` — статьи блога («Полезные советы»)
- `data/specialists.ts` — команда (имя, должность, фото, био)
- `data/reviews.ts` — отзывы клиентов
- `data/faq.ts` — общие вопросы-ответы (главная страница)
- `data/technologies.ts` — карточки оборудования

Каждая запись хранит текст в двух языках: `{ uz: "...", ru: "..." }`. Плейсхолдеры отмечены квадратными скобками — `[PRICE]`, `[DURATION]`, `[SESSIONS]`, `[DEVICE]`, `[CONFIRM]`, `[DOCTOR_TO_FILL]` — замените их на реальные данные клиники (полный список — в чек-листе ниже и в финальном отчёте, приложенном к этому проекту).

### Как добавить новую услугу

Добавьте один объект в массив `services` в `data/services.ts` со всеми полями типа `Service` — страница `/services/[slug]` и карточка на главной/`/services` сгенерируются автоматически, а её `slug` сразу появится и в выпадающем списке формы записи, и в `sitemap.xml`. Необязательные поля (`steps`, `preparation`, `aftercare`, `contraindications`, `interactiveBlock`, `bodyAreas`) можно опустить, если они не нужны конкретной услуге.

### Как добавить/изменить акцию

Добавьте объект в `data/promotions.ts` с `serviceSlug`, указывающим на существующую услугу, и `startDate`/`endDate` в формате ISO (`"2026-10-01"`). Пока даты не подтверждены (значение `"[CONFIRM]"`), акция считается активной по умолчанию — как только вы впишете реальные даты, акция скроется автоматически после `endDate` без переразвёртывания сайта (проверка идёт по времени запроса, а не времени сборки).

### Как добавить статью в блог

Добавьте объект в `data/articles.ts` — страница `/blog/[slug]` создастся автоматически. Поле `relatedServiceSlug` (необязательное) добавляет в конец статьи блок со ссылкой на связанную услугу.

## 5. Как заменить логотип и фотографии

- **Логотип**: сейчас используется текстовый placeholder-компонент `components/ui/logo.tsx` (SVG-плейсхолдер с монограммой «RM»). Когда появится готовый файл логотипа — положите его в `public/brand/` и замените содержимое `LogoMark`/`Logo` на `<Image src="/brand/logo.svg" ... />`.
- **Фото специалистов**: `public/images/specialists/placeholder-*.svg` — замените на реальные фото (с согласия сотрудников) и обновите пути в `data/specialists.ts`.
- **Фото «До/После»**: `public/images/before-after/*.svg` — **обязательно только с письменного согласия клиента**, см. комментарий в `components/sections/before-after.tsx`.
- Форматы: используйте `.jpg`/`.webp` для фотографий, компонент `next/image` сам оптимизирует размер и формат.

## 6. Чек-лист плейсхолдеров (что нужно заполнить перед запуском)

Полный список всех `[PLACEHOLDER]` / `[CONFIRM]` / `[DOCTOR_TO_FILL]` с точными путями к файлам приведён отдельно в финальном отчёте по проекту. Основные пункты:

- [x] Адрес клиники — заполнен (`messages/uz.json` / `messages/ru.json` → `contacts.addressValue`, `lib/site-config.ts` → `address`, карта в `mapEmbedSrc`) — проверьте точность перед запуском
- [ ] Часы работы — `contacts.hoursValue`
- [ ] Точка на карте — `lib/site-config.ts` → `mapEmbedSrc` (координаты Яндекс/Google карты)
- [ ] Оба номера телефона уже внесены в `lib/site-config.ts` (`phone`/`phoneSecondary`) — проверьте перед запуском
- [ ] Цены, длительность, число сеансов, модели оборудования, даты акций, противопоказания и уход после процедур — `data/services.ts`, `data/promotions.ts` (везде помечено `[PRICE]`/`[DURATION]`/`[SESSIONS]`/`[DEVICE]`/`[CONFIRM]`/`[DOCTOR_TO_FILL]`)
- [ ] Специалисты (имена, фото, био) — `data/specialists.ts`
- [ ] Отзывы клиентов (только реальные, с согласия) — `data/reviews.ts`
- [ ] Оборудование — `data/technologies.ts`
- [ ] Логотип — `public/brand/` + `components/ui/logo.tsx`
- [ ] Фото «До/После» и изображения услуг — только с письменного согласия клиента / заменить SVG-плейсхолдеры в `public/images/`
- [ ] Домен сайта — `lib/site-config.ts` → `domain` (используется в метаданных, sitemap, JSON-LD)
- [ ] Telegram-бот для формы записи — см. раздел 7

## 7. Настройка Telegram-бота для формы записи

Форма записи (`/api/booking`) отправляет заявки в Telegram.

1. Создайте бота через [@BotFather](https://t.me/BotFather), получите `TELEGRAM_BOT_TOKEN`.
2. Узнайте `chat_id` — например, напишите боту [@userinfobot](https://t.me/userinfobot) от имени нужного чата/группы, либо добавьте бота в группу администраторов и получите `chat_id` через `https://api.telegram.org/bot<TOKEN>/getUpdates`.
3. Создайте файл `.env.local` (по образцу `.env.example`) и заполните:

```
TELEGRAM_BOT_TOKEN=ваш_токен
TELEGRAM_CHAT_ID=ваш_chat_id
```

Если переменные не заданы — заявки не теряются, а логируются в консоль сервера (удобно для локальной разработки).

Форма также включает:
- **honeypot**-поле (скрытое поле-ловушку для ботов),
- простое **rate limiting** (не более 5 заявок с одного IP за 10 минут; хранится в памяти процесса — для serverless/многоинстансного продакшена рекомендуется заменить на общее хранилище, например Upstash Redis).

## 8. Деплой на Vercel

1. Залейте проект в Git-репозиторий (GitHub/GitLab/Bitbucket).
2. Импортируйте репозиторий в [Vercel](https://vercel.com/new).
3. В настройках проекта Vercel добавьте переменные окружения `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
4. Задеплойте — Vercel автоматически определит Next.js и настроит сборку (`next build`).
5. После получения домена обновите `lib/site-config.ts` → `domain` на реальный адрес сайта (это важно для корректных `sitemap.xml`, `hreflang` и Open Graph).

## Важно

- Контент, отмеченный плейсхолдерами (`[ADDRESS]`, `[PRICE]`, имена специалистов и т.д.), **не является реальными данными** — сайт не публикует медицинских заявлений, цен, адресов или лицензий, которые не были подтверждены клиникой.
- Изображения «До/После» — только иллюстративные плейсхолдеры. Реальные фото клиентов можно публиковать исключительно с их письменного согласия.
